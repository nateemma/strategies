# GAN scorecard — baseline

Generated by `GANs/quality/scorecard.py`. Spec:
`docs/superpowers/specs/2026-08-26-gan-parity-design.md`.

Fixture: 4000 rows x 24 **production** features (`FeatureNormalizer.include_list`
via `DataframePopulator` at `DatasetType.MINIMAL`, matching
`BaseNNStrategy.py:1266`), real OHLCV from 6 liquid pairs, 2025-01 onward.
Labels are forward-return terciles — a learnable proxy, NOT the gbb target.
40 epochs per variant, 300 class-balanced synthetic samples.

## READ THIS FIRST — what these numbers are and are not

**This measures RAW `generate()` output.** Production does not use raw output:
`balance.py` applies density (:322), discriminator (:342) and autoencoder filters
downstream. GAN_TODO §5 reported NNNC TabDDPM at sigma_ratio ~0.5 — that was
**post-filter** (the AE kept ~70%). This table therefore does NOT contradict §5;
it measures a different quantity. Raw output = model quality. Post-filter =
deployed quality. **Both matter and only the first is measured here.**

**Utility is a proxy.** `delta_val_mcc` = MCC(train+synth) - MCC(train) on a
held-out real split, HistGradientBoosting, fixed seed. It ranks variants; it does
not settle P&L. Anything it flags still needs the §5 powered paired-seed protocol.

**Metric meanings.** `clip band` = fraction pinned at +/-4 sigma in z-space (the
WGAN/CGAN/DDPM guard). `bound sat` = fraction sitting at the real per-column
[min,max] (CTAB's guard, `mlx_ctab_helpers.py:35`). They detect DIFFERENT
mechanisms; a variant can be saturated under one and read 0 under the other.
`NN ratio` ~1 is on-manifold, >>1 is off it.

## Findings

1. **TF is not uniformly behind — the gaps run BOTH ways.** WGAN-TF preserves
   joint structure far better than MLX (max dcorr 0.211 vs 1.141) and has much
   better marginals (worst dmu 0.229 vs 2.212); MT_WGAN-TF likewise on dcorr
   (0.559 vs 1.030). But on CTAB the MLX side is better on nearly every axis.
   "Bring Keras up to MLX" is the wrong framing for the WGAN family, where MLX
   is the weaker implementation.

2. **Both DDPMs show sigma_ratio ~3.9 and clip band ~0.96-1.0 on raw output.**
   Confirmed NOT under-training (400 epochs only moves it 3.97 -> 3.44) and NOT
   under-capacity (production d_model=256 gives 3.88 vs toy d32's 3.94). This is
   what the AE filter downstream exists to clean up — see the caveat above.

3. **Every variant has a NEGATIVE delta_val_mcc** (-0.002 to -0.034) on this
   target. Consistent with GAN_TODO §4/§5: augmentation on the same features does
   not add information. Best is MT_CTAB_GAN-MLX (-0.0024), worst MT_WGAN-MLX
   (-0.0338). Do not over-read the ordering — these are all near zero.

4. **CGAN has no MLX backend**; `resolve_backend(prefer_mlx=True)` silently falls
   back to TF. The driver records this rather than double-counting the TF row.

5. **Fit time spans 50x** (MT_WGAN-TF 103.7s vs MT_WGAN-MLX 1.9s) on identical
   data. Relevant to anyone running the TF path on non-Mac hardware.
