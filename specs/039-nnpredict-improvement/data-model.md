# Data Model: 039 NNPredict Improvement Study

## Arm

| Field | Meaning |
|---|---|
| `tag` | e.g. `nnp_ridge`, `nnp_ridge_sa`, `nnp_lstm_raw`, `nnp_lstm_ind`, `nnp_lstm_ret`, `<M>_fw0`, `<M>_g24`, `<M>_hpa`, `<M>_famm`, `<M>_gate`, `nnp_cs` |
| `class` | the strategy class (fold classes `<class>_fNN` are generated by run_folds) |
| `plan` | `evaluation/folds/plan_<tag>.json` (family `NNPredict`, 15 folds, config_wf, seed 1) |
| `comparator` | the arm it is judged against (data-model § Verdict) |
| `stage` | models / framework / sizer |

**Fold record**: `regime/arms/<tag>_fNN_FNN.json`, written by run_arm. Holds the trades, `trades_hash`,
`n_trades` and the model key.

## Stage comparators

| Stage | Arm | Comparator | Decision |
|---|---|---|---|
| models | `nnp_ridge` | — | reported beside `w_aro`, `cs_aro`, `st_g24_mom` |
| models | `nnp_ridge_sa`, `nnp_lstm_*` | `nnp_ridge` | `judge_one` |
| framework | `<M>_fw0` | `<M>` | identity: `trades_hash` equal on 15/15 folds |
| framework | `<M>_g24`, `_hpa`, `_famm`, `_gate` | `<M>_fw0` | `judge_one`; PASS → candidate family default |
| sizer | screen | the ARO bar | pass rule (R8) |
| sizer | `nnp_cs` | `w_aro` (must PASS); `cs_aro` (reported) | `judge_one` |

`<M>` = the R7-selected model arm.

## Screen result (`research/nnpredict/screen.json`)

| Field | Meaning |
|---|---|
| `trades`, `instrument` | 412 trades; the reproduced 0.1004 control gap |
| `coverage` | share of trades with a finite score |
| `gap_share50` | mean pp of the top half minus the bottom half by score, within fold |
| `partial` | Spearman partial correlation of score with pp, given bb_width |
| `sign_folds` | folds (of 8) whose partial has the pooled sign |
| `rho_pctl` | Spearman correlation of the score with the control's p_buy (orthogonality, reported) |
| `pass` | per R8 |

## Verdict (`research/nnpredict/verdicts_<stage>.json`)

Per arm: `judge_one` output (verdict, arm and control pp, early and late gains, paired, risk,
`folds_changed`), plus a decision string. The framework stage also records the identity result and
the R7 selection.
